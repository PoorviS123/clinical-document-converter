# ICH M11 Step 4 Technical Specification: extraction notes

Sources: TechnicalSpecification_2025_1119.pdf (primary, 245 pages), `M11 to FHIR Mapping 02.xlsx` (sheet Mapping, 324 rows; Narrative Section Mapping, 158 rows), `ICH M11 Terminology.txt` (586 rows, 39 codelists).
Page citations (`pdf_page`) are 1-based PDF file page indices (cover = page 1); a range like `9-10` means the element record spans a page break. Appendix 1 starts on PDF p.4 and the last record is on p.245.

## Counts
- PDF has 575 "Term (Variable)" records: 282 heading-only records (`m11_headings.json`, includes 8 "universal text" fixed-sentence records) and 293 data elements (`m11_elements.json`). 291 are marked D/V; 2 are marked H but carry a C-code and "Value Allowed: Yes" so are treated as data (PDF typos): id 206 `{Description of Intercurrent Event}` for 3.2.X (p.87) and id 546 `[Country/Region Identifier]` C218832 (p.230). Flagged `pdf_dvh_anomaly: true`.
- Not all 293 are separate NCIt concepts: several records are composite "A or B" records carrying 2 codes (`ncit_codes` list): Country/Region/Site Identifier (C20108, C218674, C83081), Sponsor Approval Date or location (C132352, C218484), sponsor signatory (C222014, C222064), Medical Expert contact (C218693, C222063), and the two planned-duration records (value + unit codes). `ncit_code` is the first code.
- `id` = 0-based index of the record among all 575 PDF Term records (stable key; headings share the numbering space).
- data_type (my normalisation; the PDF only says Text / Valid Value / Number / Date etc. and does NOT distinguish narrative from short text):
  - narrative 143 (section body text under numbered headings; derived rule below)
  - text 76 (short free text: title page names/addresses, table cells in estimand/6/9.2/12.3 tables, objective statements, I/E criteria)
  - identifier 14, integer 7 (incl. the two criterion `<#>` numbers, flagged `is_identifier`), date 3, date_or_text 1, image_or_text 2, table_text_image 1 (Schedule of Activities), generated_toc 1
  - coded: coded_value 34 (codelist from Terminology), coded_value_external 7 (ISO 3166/GENC, IDMP/SDTM, MedDRA/SNOMED, WHO INN: no ICH codelist), coded_value_inline 2 (Target/Maximum; randomly assigned/enrolled: pick-lists written in the PDF with no codelist or codes), integer_with_coded_unit 2 (planned duration + C217048 unit). Total coded-ish = 45; 7 of the 34 coded_value are Yes/No (C217046, `boolean_like`).
  - Rule for narrative vs text (derived, not in the PDF): `pdf_data_type == Text`, numbered section (not Title Page/Amendment Details/1.1.2/3.x/6/9.2/12.3), not in a table per Relationship/Cardinality text, not an I/E criterion row. Review borderline cases if the schema needs a different cut.
- conformance: Required 126, Conditional 94, Optional 72, blank 1 (id 531 `<Trial Monitor Expectations for Source Records>`, p.224: Conformance field empty in PDF). The `conformance.level` is the first word of the PDF text; `condition` is the remainder (PDF has variants such as "Optional: if the table used", "Optional if the table is used", "Required Either ... or", "Required: Co..."; verbatim in `pdf_text`).
- cardinality: PDF uses prose ("One to one", "One to many", "One to each Arm Name"). `cardinality` is DERIVED from the first clause + conformance level (Required -> lower bound 1, else 0; "many" -> `*`). 0..1 147, 1 123, 0..* 19, 1..* 2, none 2 (ToC "N/A" and id 211/others with non-"One to" wording). Use `cardinality_pdf` and `repeatable` / `repeats_with` for the real semantics: the PDF cardinality is relative to the element's parent, and repeating is stated separately in "Repeating and/or Reuse Rules" (`repeat_rule_pdf`).
- Codelists (`m11_codelists.json`): 39 total. 23 are value codelists referenced by data elements; 16 are "ICH M11 Section N / Title Page / Amendment Details Terminology" lists (`section_name_codelist`) that hold the element-name -> NCIt code concept lists (they are NOT value lists). C217272 "Protocol Section Name and Number" (160 terms = 158 section headings + Title Page C222769 + Amendment Details C222770) is the value list for `<Section # and Name>` (>40 terms, so `allowed_values` is null with a note). Terminology.txt has no separate "submission value" column; `submission_value` in codelists JSON = ICH Preferred Term (same as `ich_preferred_term`); `ich_synonyms` and `nci_preferred_term` are given separately.
- OIDs: element concept OIDs are in `ncit_oids` (code -> OID, 2.16.840.1.113883.3.989.2.3.3.N where N is by section group) and codelist OIDs in `codelist_oid`. Note the PDF reuses OID suffix .1.18 for both Trial Phase (C217045) and Intervention Assignment Method (C217280), and .3.13 (no .1.) for C217272; copied as printed.

## xlsx vs PDF
- xlsx rows 324; 318 attached to a PDF element (6 unattached are "heading" placeholder rows: 5.4, 8, 9, 10, 11, 12). 284 of 293 PDF elements have a usdm mapping; matching = NCIt code within section, else normalised name similarity, plus 34 manual pairings (41 xlsx rows) (listed in `stage3.py` MANUAL; each mapping records `match` = code/name/manual so you can audit). Some PDF elements map to several xlsx rows (e.g. Treatment -> 5 USDM paths; Units of Age -> min and max).
- PDF elements with NO xlsx row (9): Table of Contents (87); `{[Nonproprietary Name] or [INN] or "Not applicable"}` composite (106); Randomisation Type C223137 (119); Stratification Indicator C223136 (122); Schedule of Activities C132349 as a data element (159; xlsx only has it in the narrative sheet); 3.3 `Table of Estimand Characteristics` (211; 3.1 and 3.2 have it); Rationale for Trial Duration 4.2.4 C218732 (244; xlsx skips 4.2.3 -> 4.2.5); Other Event Type C222263 (417); Additional Appendices C220640 (570). Also no usdm for conditional "Other description" (ids 66, 70) and "If yes, briefly explain" (75, 78) beyond a manual link to xlsx rows that have no target path, and Amendment Details (56, no path).
- xlsx rows with no PDF element: only the 6 heading placeholders. xlsx has 2 label rows ("Secondary/Exploratory Objective <#>" C85826) that map to the objective record in PDF.
- NCIt codes: xlsx carries "CNEW" for 161 of the elements the PDF now gives a code (xlsx predates code assignment). Use PDF/Terminology codes. Real code conflicts (also: xlsx maps Secondary/Exploratory objective label rows with C85826 while PDF codes the objective statement C85827/C163559): Background Trial Intervention PDF C222329 vs xlsx C165822; Rescue Therapy C222330 vs C165835 (xlsx values are actually Intervention Use *term* codes); Identification of Source Records C222675 vs C125442 (xlsx "Source Data" naming); Country/Region Identifier (12.2) C218832 vs xlsx "C20108 or CNEW"; Sponsor Legal Address: PDF gives C222495 (same as Sponsor Name; p.15-16) but Terminology section list has Sponsor Name = C222495 and Sponsor Legal Address = C218677 (xlsx notes this too). Terminology wins for C218677.
- xlsx "Codelist Ref" column is unreliable for typing: for 17 coded elements it holds a USDM/NCIt TERM code, not the M11 codelist (e.g. Intervention Model C82637 = "Cross-over" term; Control Type C49649 = Active Comparator term; Units C25301 = Days term; Blind Schema C15228; Yes/No given as C49487 or "217046" without C; Arm Type C174267; Intervention Type C15184; Use C41161; Event Type C41331), and "CNEW" for 7 more (Population Type, Site Distribution, Site Geographic Scope, Blinded Roles, IMP/NIMP, Sourcing, Prior Amendment/Section lists). Use the PDF/Terminology codelist codes in `codelists[]`.
- xlsx "Required" column is populated for Title Page only and is not the same vocabulary (Yes/No/"One of ..."/"yes if amended"); consistent with PDF Required/Optional/Conditional where both exist (No->Optional, Yes->Required/Conditional). Use PDF.
- xlsx section-number glitches: row 139 is under `3.2.#` but is the Exploratory objective's Population-level Summary (paired to PDF 3.3.X, id 221). xlsx names differ cosmetically ("Source Data" vs PDF "Source Records", trailing period on "Contraception Requirements.", "INN", "Heading"/"heading" rows).
- Title page codes/types where xlsx and PDF agree but xlsx target is odd: Medical Expert contact -> `Address.text`; Sponsor signatory and "describe method" -> NarrativeContentItem (xlsx uses CNEW codelist).

## Structure of key groups

### Title page identifiers (all Text; Title Page; pp.5-25)
- Sponsor Confidentiality Statement C181236 (Optional, 0..1); Full Title C132346 (Required); Trial Acronym C94108 (Opt); Sponsor Protocol Identifier C132351 (Required; non-empty, p.7); Original Protocol Indicator C218672 (Required, Yes/No C217046); Version Number C181232 (Opt, text); Version Date C93813 (Opt, date); Trial Short Title C94105 (Opt).
- Identifiers (Optional, 0..1 each, text): EU CT C218684, FDA IND C218685, IDE C218686, jRCT C218687, NCT C172240, NMPA IND C218688, WHO/UTN C218689 (format Uxxxx-xxxx-xxxx, p.22), Other Regulatory or Clinical Trial Identifier C218690 (repeatable per regulatory agency identifier). So registry identifiers are fixed named fields, not a generic repeating (type, value) pair, except the "Other" one.
- Products: Sponsor's Investigational Product Code(s) C218675 and Nonproprietary Name(s) C97054 and Proprietary Name(s) C71898 (repeatable); Trial Phase C48281 (Required, C217045, 11 terms).
- Organisations: Sponsor Name + Legal Address (Required; both given code C222495 in PDF), Co-Sponsor Name C218678/Address C218679, Local Sponsor C218680/C218681, Device Manufacturer C218682/C218683; each Optional, repeatable; address is 1 per name.
- Approval/sign-off: Sponsor Approval Date C132352 OR location text C218484 (Required, date_or_text, "Yes, not repeatable", reused in 12.3); Sponsor signatory C222014 (text and/or image) or location C222064 (Optional); Medical Expert contact C218693 or location C222063 (Optional).

### Amendment details (Title Page + "Amendment Details" block, pp.9-39)
- Title page amendment table: Amendment Identifier C218477 (Conditional on amendment; repeatable "Table for Document History"), Amendment Scope C218673 (C217047; Blank if original), Country/Region/Site Identifier C20108/C218674/C83081 (Conditional when scope is not Global; ISO 3166 / GENC / free-text site; repeatable per 12.2).
- Amendment Details block: statement C218694 (Required, C217274 4 terms); Approximately <#/%> enrolled C218478 (Number: integer or one decimal for percent; Conditional on Original Protocol = No); Enrollment scope C218695 (C217275: Globally C68846 / Locally C41065 / By Cohort C218489); Primary Reason C218696 and Secondary Reason C218697 (both C217276, 15 terms, multiple values allowed, not for original); "Other description" C17649 conditional on Other; Amendment Summary C42581; two substantial-impact Yes/No flags (C218698 safety/rights, C218700 data reliability) each with conditional explanation text (C218699, C218701); change table rows repeating per Description of Change: Description C218483, Brief Rationale C181233, Section # and Name C218479 (C217272, 160 terms). 12.3 Prior Protocol Amendment(s) repeats the same fields per prior amendment (ids 550-568).

### 1.1.2 Overall Design key aspects (36 elements, pp.43-66)
Product codes C218675 / nonproprietary names C97054 (Required either/or; repeatable); Intervention Model C98746 (C217277, 6); Population Type C218703 (C217278, 2); Control Type C49647 (C217279, 7); Population Diagnosis or Condition C112038 (text/MedDRA/SNOMED, repeatable); control product names/INN C97054/C142585 or "Not applicable"; Min/Max Age C49693/C49694 (integer) + Units of Age C50400 (C217048, Hours/Days/Weeks/Months/Years); Intervention Assignment Method C218475 (C217280, 3) with conditional Randomisation Type C223137 and Other method C223138 (text); Stratification Indicator C223136 (Yes/No); Site Distribution C218704 (C217049); Site Geographic Scope C218705 (C217050); Master Protocol C218707, Drug/Device Combination C218708, Adaptive Design C218706 (Yes/No); Number of Arms C98771 (integer); Trial Blind Schema C49658 (C217051, 4); Blinded Roles C218709 (C217281, multi); Target/Maximum C218710 (inline) + Number of Participants C49692 (integer) + "randomly assigned/enrolled" C218711 (inline); planned durations of intervention (C218712 integer + C218713 unit) and participation (C218715 + C218716) with alternate-description text C218714/C218717 when duration varies; Additional Description of Duration C218838; Independent Committees C218718 and Other Committees C218719.
- Note the "Overall Design" section also has the fixed sentence "Key aspects of the trial design are summarised below" (universal text, p.42, headings file).

### Estimands (3.1 primary, 3.2 secondary, 3.3 exploratory; pp.74-94)
- Per objective X: heading `3.n.X <Primary|Secondary|Exploratory> Objective <#>`; objective statement text C85826 (primary, the objective itself; xlsx labels it C85826 and text C85826) / C85827 secondary / C163559 exploratory (Required for primary and secondary, Conditional for exploratory); then an "Estimand Characteristics" table (Description column) with attributes, ALL free text, one row per attribute, repeated per numbered objective (`repeats_with` = "each numbered ... Objective"):
  - Population C70833 (Conditional: if a population is an estimand characteristic)
  - Treatment C49236 (Conditional)
  - Endpoint C25212 (Required for Primary; Conditional for Secondary "if there is a Secondary Objective" and Exploratory "if there is exploratory endpoint(s)")
  - Population-level Summary C188853 (Conditional)
  - Intercurrent events: Description of Intercurrent Event C188856 and Intercurrent Event Strategy C188857, Conditional on "one or more other intercurrent events", repeatable per intercurrent event (cardinality for description "One to one or as many intercurrent events as available"; strategy 1 per event). There is NO codelist for strategy; text only (E9(R1) strategy names appear only in user guidance). Table-header records "Other Intercurrent Event" and "Strategy" are H.
  - 3.2/3.3 also have a `{Table of Estimand Characteristics ...}` record (conformance: either the table OR details of characteristics; Text, N/A definition) and 3.1 has "Estimand Characteristic" heading. Section 10.4.X/10.5.X statistics sections repeat per objective too.
- 1.1.1 `<Primary and Secondary Objectives and Estimands>` C218839 (Required, narrative) reuses (repeats) the 3.1/3.2 objective and endpoint content (p.41).

### Intervention table (Relationship content "6", pp.120-129)
Table is optional ("Optional: if the table used") with header records for Arm Name C93729 (0..*), Arm Type C172457 (C217283, 6: Active Comparator Arm/Control Arm/Experimental Arm/No Intervention Arm/Placebo Comparator Arm/Sham Comparator Arm), Intervention Name C177930 (text), Intervention Type C98747 (C217284, 12), Pharmaceutical Dose Form C42636 (IDMP ISO 11239 or CDISC SDTM; external), Dosage Strength(s) C142517 (text), Dosage Level(s) C94394 (text), Route of Administration C38114 (IDMP/SDTM external), Regimen/Treatment Period/Vaccination Regimen C15697 (text), Use C218748 (C217285, 7), IMP or NIMP C218749 (C217286, 2: IMP C202579, NIMP C156473), Sourcing C218750 (C217052, 2). Repeat rules nest: arm name -> arm type -> intervention name -> type/dose form/strength/level/route/use per arm and intervention combination. The overview text above it is C218747 (Required, text, p.120). 6.1 and later (6.2-6.10) are narrative elements.

### Committees
1.1.2 Independent Committees C218718 (Required, 1..*, C217282: IDMC C142578, Dose Escalation C215671, Endpoint Adjudication C78726, Other C17649, None C41132) + Other Committees C218719 (Optional text); 11.4 `<Committees>` C218819 (Required narrative). xlsx maps both 1.1.2 items to StudyRole.label.

### Section-level narrative elements
143 narrative-typed data elements (Text, one per section, mostly `One to one`; conformance Required in most; Conditional for "{...}" optional sub-headings such as 5.5 Lifestyle Restrictions, 6.7.2-6.7.4, 6.9.1-6.9.3, 6.10.1-6.10.2, 8.2 Baseline, 8.4.1-8.4.6, 8.6.3, 9.3.1-9.3.2, 11.2 Trial Oversight, 11.3.1-11.3.2, 12.X Additional Appendices; Optional for 2.2.x, 4.1.x, 4.2.x, 5.5.x etc.). Separately, section headings themselves have NCIt codes (C218514-C218671, 158 headings) only in the xlsx Narrative Section Mapping sheet and in Terminology C217272; the PDF gives headings no code ("Concept: Heading"). These are added to `m11_headings.json` as `section_heading_ncit_code`. Statistical narrative sections 10.4.X.1-5 and 10.5.X.1-5 repeat per objective. 12.2 Country/Region-Specific Requirements/Clarifications repeat per country/region. Text-bearing "universal text" headings (fixed template sentences) are not data elements (8 in headings file).
