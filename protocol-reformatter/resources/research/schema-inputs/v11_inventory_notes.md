## Method
1. Parsed `document.xml` body children in order with python-docx 1.2.0 + lxml. Tracked changes: the document has none (0 ins/del/moveFrom/moveTo); `visible_text` logic (skip w:del / w:moveFrom) was still applied. Only SDT at body level is the TOC; the 17 inline SDTs are empty goog_rdk tags.
2. Heading numbers are NOT style-driven: the `01Heading 1`..`04Heading 4` styles carry no numPr. Each section uses a different `numId` -> its own abstractNum with hand-set `start` values (e.g. list 131: lvl0 start 3, so "3.1" appears before the first "4"). I simulated Word's list counters (counters per abstractNum, deeper levels reset, skipped parent levels take their start value, and are treated as already started) and parsed typed numbers where the heading text itself carries the number (9.1.1, 10.4.1, 10.4.1.1, 10.4.1.2, 10.8.1, 10.8.2, 11.2.1, 11.2.2, 12.4). **Result checked against Word's cached TOC: all 159 level 1-3 entries match exactly by number and title.**
3. Per-heading content = all body blocks until the next heading. Classified paragraphs: instructional (CPT_Instructional / CROMS_Instruction / "Instructional TExt" outside a marked region), region markers (`<Start|End of common|suggested|example text ...>`), live/common/suggested text and tables. Placeholders = `[...]` (nested) and `<...>`; kinds inferred only from template wording (`[yes/no]`, `[A/B]` -> choice with allowed_values, "ICH M11 Controlled Terminology" -> controlled_term). Placeholders inside `example` regions are counted, not listed; tables are always listed (with `region`).
4. Hand-curated overlays (read from the document): all title-page fields, Amendment Details tables, 1.1.2 key-aspects table cells, 3.x / 10.x repeating structure, section-6 arm table columns, 5.2/5.3 criteria tables, 1.3 SoA structure, 12.3 tables, heading placeholder in 5.7.
5. M11 cross-check: `pdftotext -layout` of the Step 4 template; parsed its TOC (headings, `{braces}` = conditional/optional heading) and each section body (`No text is intended here (heading only)` flags). Compared by heading number.
6. `text_expected`: "none" / "none_unless_not_applicable" taken from the literal instruction `No text is intended here (heading only)`; else "text". **Identical to M11 for all 159 shared headings** (25 headings; 3.2, 3.3 and 10.5 are the "unless there is no ..., indicate Not applicable" variants).
7. `optional` = true if (a) heading text is bracketed, or (b) M11 TOC shows the heading in {braces}, or (c) for L3+/unnumbered headings an instruction says can/may be deleted, required only for devices, optional subheadings (parent instruction), or "may be required in certain types of studies". L1/L2 are optional only when bracketed (5.8) plus 12.4 (explicit "Delete appendix if not required."). `optional_basis` states the reason. 49 body nodes are optional.
8. `required` = true when a "required Level 3/4 heading" note names the section (3.1.1; 5.4.1-5.4.2; 6.6.1-6.6.3; 6.7.1; 7.1.1-7.1.3; 8.6.1-8.6.2; 9.1.1-9.1.3; 9.2.1-9.2.5; 10.4.1, 10.4.1.1-10.4.1.3) = 24 nodes. Note the CPT notes for 9.1.1-9.1.3 and 9.2.1-9.2.5 are phrased "common text and must be maintained".

Renamed/retitled: 10.5 "Analysis Associated with the Secondary Objective(s)" (CPT, typo) vs "Analyses Associated ..." (M11). Spelling only: Randomization/Randomisation (6.7, 6.7.2), Utilization/Utilisation (8.8), Behavior/Behaviour (8.4.6); 8.6.1 M11 has an Oxford comma "Pharmacogenetics, and Pharmacogenomics". Optionality markers: M11 braces 30 shared headings (3.2.1, 3.3.1, 6.7.2-6.7.4, 6.9.1-6.9.3, 6.10.1-6.10.2, 8.4.1-8.4.6, 8.6.3, 9.1.3.1, 9.3.1-9.3.2, 10.4.1.4-10.4.1.5, 10.5.1 and 10.5.1.1-10.5.1.5, 11.3.1-11.3.2). Placeholder notation differs: M11 `Primary Objective <#>`, CPT `[#]`.
Content-slot differences:
- Section 6 arm/intervention table: M11 has 12 columns including **Sourcing** (`[Select Sourcing]`); the v011 table has 11 (ends at IMP/NIMP) although its Table Instructions list "Sourcing". M11 footnote "NonInvestigational/Auxiliary Medicinal Product" vs CPT "Noninvestigational Medicinal Product". M11 marks the table optional.
- Title page: v011 merges Sponsor/Co-sponsor into one repeatable pair; M11 has separate Sponsor, Co-Sponsor and Local Sponsor groups. v011 has a single repeatable "Investigational Product Name(s)"; M11 has Nonproprietary Name(s) and Proprietary Name(s) separately. v011 regulatory identifiers = free Label|ID table ([Agency]|[ID Number]); M11 has fixed fields (EU CT, FDA IND, IDE, jRCT, NCT, NMPA IND, WHO/UTN, Other). v011 adds a hidden structured-title helper list (Intervention Model, Primary Purpose, Trial Phase, Blinding, Number of Arms, Health Measurement/Outcome, Investigational Intervention, Intervention Form, Participant Sex, Participant Age Range, Condition/Disease) not in M11. v011 brackets Version Number, Version Date, Trial Acronym labels.

- 3.1.1: M11 has an explicit `<Enter Primary Objective>` slot and braces the Population/Treatment/Population-level Summary/ICE rows (Endpoint is the only unconditional row); v011 has no objective-text slot and no braces.
- 1.3 SoA: M11 instruction contains "Allowable windows should be stated for all visits and procedures."; v011 omits it.
- 12.3: M11 "Approximate Enrollment when Sponsor Approved Amendment" column is unbracketed (universal); v011 brackets it (optional). Column labels differ slightly (`<Enter Amendment Identifier>` vs `[Amendment X]`; "Sponsor Approval Date" vs "... (dd/mmm/yyyy)").
- Template preamble: CPT "About This Template" (disclaimer, libraries, terminology, complex-trial guidance) replaces M11 Section 0 Foreword; neither is protocol content.

## Ambiguities / things I could not resolve
- Level-4 numbers are computed (L4 is not in the cached TOC, which covers Heading 1-3 only). 10.4.1.3-10.4.1.5 and 10.5.1.1-10.5.1.5 depend on list start values (lvl3 start=3 in list 108; lvl1 start=5 in list 111) and match M11 and the CPT's own cross-references ("Section 10.4.1.5 Supplementary Analysis"); I could not render in Word to see them.
- 9.1.3.1 uses style 03Heading 3 at numbering depth 4 (TOC lists it as toc 3). I report level 4 (by number) and style 03Heading 3.
- Allowed values of controlled terms (Intervention Model, Blinding, Trial Phase, Arm Type, ...) are not in the template; only the ICH M11 CT URL is given. `allowed_values` is therefore null for those. "Global"/"Not Global" (Amendment Scope) are quoted from instruction prose, not a pick list.
- Whether the sponsor signatory table may hold several signatories is not stated (`repeatable: null`). Stratification Indicator kind is `controlled_term` because the template shows `[Stratification Indicator]` (not `[yes/no]`).
- Several field-label paragraphs are styled as instructional text (`CPT_Instructional`: "Number of Arms:", "Trial Blind Schema:", "Total planned duration ...", "Committees:", "[Short Title]:"; `Instructional TExt`: Blinded Roles sentence). Style-based stripping of instructional text would delete live slots (see `style` on those slots). The "Amendment status" statements use `Instructional TExt` inside common-text markers.
- Stale internal cross-references in v011 (instruction/common text): "Section 6.9.4 Medical Devices" (heading is 6.1.1); "Refer to Section 7.1.2 for [QTc] withdrawal criteria" (QTc criteria are 7.1.1.2); "Appendix [6: Liver Safety ...]" in 12.1 notes (heading is 12.4); "Section 12.3, Protocol Amendments" (heading is "Prior Protocol Amendment(s)"). "Section 3.1.1 is a required Level 3 heading" and the analogous 10.4.1 note were applied by number.
- `value_slots` for body headings are auto-detected from template wording except the curated nodes listed in Method step 4; slots in `example` regions are summarized (`example_text_present`, table slots with `region: example`) rather than enumerated.
- Heuristic fields (`not_applicable_rule`, `key_instructions`) are sentence extracts of the instruction text, capped at 6 / 12 per node; full instruction text is in the docx at `source_block`..`source_block_end` (block index = body child index).
- Title page "Trial Phase" appears twice in v011: once as structured-title helper and once as the field `Trial Phase: [Trial phase]`.
- 4.2 (Rationale for Trial Design) permits "Overall rationale ... if not using below optional subheadings"; I mark 4.2.1-4.2.7 (and 11.2.1-11.2.2, 5.5.1-5.5.4) optional from the parent's instruction, although M11 does not brace them.
